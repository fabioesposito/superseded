How it works

Five passes, one command

Each pass sends a curated prompt to an AI agent in parallel. Findings come back as structured JSON — merged, deduplicated, and sorted by severity.

Diff

Fetch the diff

Pull from a GitHub PR via gh or a local git diff range.

Memory

Load feedback memory

Query the local SQLite store for previously dismissed findings. Inject as negative context so the agent avoids repeating patterns you've already rejected.

⚡

Run static analysis

Auto-detect linters and scanners (ruff, mypy, eslint, bandit, gitleaks, go vet, …) and run them over changed files. Deterministic signals injected as context before the AI sees the diff.

Retrieve cross-file usages

Extract symbols from changed code, then use ripgrep to find callers across the repository. Surfaces breakage risk that a human reviewer might miss.

Review

Run 5 passes in parallel

Each pass focuses on one concern with a domain-specific prompt. All five run concurrently via ThreadPool.

security correctness performance style architecture
Merge

Merge and deduplicate

Combine findings across all passes. Sort by severity. Drop duplicates found by multiple passes.

Output

Output results

Terminal table for quick scanning, JSON for piping, or markdown for docs. Optionally post inline review comments to the GitHub PR.

Features

Built for real workflows

CLI for local dev. GitHub Actions for CI. Self-hosted server for teams. Memory that improves over time.

Multi-pass review

Five specialized passes with focused prompts. Security, correctness, performance, style, and architecture — each with domain-specific instructions. Catches issues a single generic pass would miss.

Feedback memory

Dismiss a finding once and it won't appear again. SQLite store tracks which findings humans reject — and why the agent flagged them. Future reviews learn from your team's decisions.

GitHub integration

Post findings as inline PR review comments. Critical issues request changes. Suggestions post as comments. Uses gh CLI — no API keys to manage.

Pluggable agents

Use Claude Code, OpenCode, or Codex. Each has its own adapter. Choose per-review or configure as default. Bring your own API keys.

Structured output

JSON for piping to other tools. Markdown for docs. Terminal table for quick scanning. Every finding has severity, file, line, and suggestion.

CI-native

Docker-based GitHub Action. Runs on every PR. Configurable passes and agents. Results posted directly to the PR as review comments.

Server mode

Run as a persistent GitHub App. Multiple repos install your app and get automatic reviews on every PR. Webhook-driven, configurable concurrency, status checks.

⚡

Static analysis pre-pass

Auto-detects linters and security scanners from your repo config. Runs them over changed files before the AI sees the diff. Deterministic signals, zero config.

Cross-file usage retrieval

Extracts symbols from changed code, then uses ripgrep to find callers across the repository. Surfaces breakage risk that a human reviewer might miss.

Reasoning trail

Each finding includes the agent's rationale. When humans dismiss a finding, the reasoning is persisted and fed back as context. Collapsible details in markdown and PR comments.

Server mode

Self-hosted for teams

Run Superseded as a GitHub App on your own server. Multiple repos install it and get automatic reviews on every PR.

Create a GitHub App

Set up a GitHub App with webhook URL pointing to your server. Subscribe to PR and installation events.

Install on repos

Other repos install your app with one click. The server tracks installations automatically.

⚡

Webhook triggers review

PR opened or updated — webhook arrives, job queued, review runs in background. Results posted as PR comments and status checks.

Configurable concurrency

Control how many reviews run in parallel. Jobs queue when at capacity. Each review gets its own shallow clone and agent subprocess.
