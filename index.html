How it works

From diff to findings in seconds

Fetch the diff, gather context, run 5 AI passes in parallel, then merge and output results.

1

Fetch

Pull diff from a GitHub PR or local git range.

2

Context

Load feedback memory, run static analysis, gather cross-file usages.

3

Review

5 AI passes run in parallel with domain-specific prompts.

SECURITY CORRECTNESS PERFORMANCE STYLE ARCHITECTURE
4

Output

Terminal table, JSON, markdown, or inline PR comments.

Features

Built for real workflows

CLI for local dev. GitHub Actions for CI. Memory that improves over time.

♦

Multi-pass review

5 specialized passes with domain-specific prompts running in parallel via ThreadPool.

♣

Feedback memory

Dismiss a finding once and it won't appear again. SQLite store learns from your team.

♥

GitHub integration

Post inline PR review comments. Critical issues request changes. Uses gh CLI.

♠

Pluggable agents

Use Claude Code, OpenCode, or Codex. Choose per-review or configure a default.

○

Structured output

JSON for piping, markdown for docs, terminal table for quick scanning.

▣

CI-native

Docker-based GitHub Action. Runs on every PR. Configurable passes and agents.

Get started in 30 seconds

Install and run your first review.

$ pip install superseded
$ superseded review --diff HEAD~1..HEAD
